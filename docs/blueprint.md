# **App Name**: Mining GATE Navigator

## Core Features:

- Resource Search: Enables searching through available notes, PDFs, video lectures, and PYQs.
- AI-Powered Question Answering: Integrates Gemini API to provide answers to user-submitted questions related to mining engineering. The AI acts as a tool, determining when its knowledge base is relevant.
- Syllabus Overview: Presents the GATE Mining Engineering syllabus in a collapsible format.
- Handwritten Notes: Showcase handwritten notes with chapter wise filtering
- Solved PYQs: Access solved Previous Years' Questions (PYQs) with a youtube link.
- Formula Cheat Sheet: Downloads all important formulas in pdf format.

## Style Guidelines:

- Primary color: Deep blue (#1A5276) to reflect knowledge and stability.
- Background color: Light blue (#D4E6F1) to provide a calm and clean backdrop.
- Accent color: Yellow (#F4D03F) to highlight important information and interactive elements.
- Body and headline font: 'Inter' for a modern, neutral, and readable design.
- Use clear and concise icons to represent different sections and resources.
- Maintain a clean and organized layout with clear hierarchy and spacing.
- Use subtle animations for transitions and interactions to enhance user experience.
